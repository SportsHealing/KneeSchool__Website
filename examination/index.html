The Clinical Examination Academy

Section 4 · What the hands can tell you, and what they cannot

Twenty-four chapters on examining the knee, written for medical students, MRCS and FRCS candidates, and fellows. 72 of 227 pages are published; the rest are written in syllabus order.

How to read a claim about a test

Examination is not a cheaper scan. It answers a different question, and the commonest error in knee practice is treating an image as the answer to a question only the examination asked.

  • Four tiers, not seven. Medical student, MRCS, FRCS and fellowship. There is no junior, patient or consultant tier in this section, which the architecture sets in a single sentence. See decision 024.
  • No test carries an accuracy figure. You will not find a sensitivity or a specificity anywhere in this section. The comparative standing of the tests is standard teaching and a specific percentage written from memory is the same class of claim as an invented citation, so the pages state the comparison and the gate refuses the number. See decision 023.
  • Where It Misleads is a section, not an aside. Every test fails in patterned ways: an effusion limits a Lachman, guarding abolishes it, an anaesthetised knee exaggerates it. A template with nowhere to say so teaches the manoeuvre and omits the thing that makes a clinician wrong.
  • The page map for this section is provisional. Part 1 of the architecture carries the full page map for Sections 0 to 3. Section 4's arrives in Part 2, which this build does not have, so its tiers and boundaries come from one sentence in Part 1 and its scope lines are page titles restated. See decision 024.
