What This Covers

The eleven pages in chapters 0.1 and 0.2 were not written to a syllabus. They were written about the knee, and a good deal of the knee is already on the syllabus.

This page maps the overlap. It is here for a teacher setting reading, and for a student who wants to know which of this material will come up in an examination.

How to Use It

Each page is between four hundred and seven hundred words, which is a realistic piece of homework reading or a ten minute task in class.

Every page ends with key learning points, and those work directly as comprehension questions.

The Knee Explorer Certificate in chapter 0.6 gives five questions covering both chapters, which can be used as an end of topic check.

The site's own curriculum page, linked below, sets out the seven level structure if you want to send a stronger student deeper into the same topic.

What to Watch For

Two things are worth knowing before you set this reading.

Chapter 0.2 covers injuries. Some students in any class will have had one, and a few will be recovering from one now. The pages are written to send a worried reader to an adult rather than to reassure them, and a student may well come and ask you something afterwards.

None of this material is clinical advice and it cannot be used to work out what is wrong with a particular knee. If a student asks, the answer is to get it looked at by a doctor or physiotherapist.

Where to Find Out More

The curriculum page on this site explains the seven level structure in full.

Chapter 0.7 holds the lesson plans, the classroom materials and the guidance written for teachers and coaches.

Your examination board publishes the current specification, which is the version that counts.

Key Learning Points

  • The eleven Junior Academy pages overlap substantially with GCSE and A level biology and PE.
  • Each page is short enough to set as a single homework reading or in class task.
  • The key learning points on each page work as comprehension questions.
  • Specifications are revised, so check the mapping against your own board.
  • None of the material is clinical advice and it cannot diagnose a particular knee.

If any of this sounds like something happening to you, speak to a parent, teacher, coach or doctor.
