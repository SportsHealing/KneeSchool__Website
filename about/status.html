Build status

What is done, what is waiting, and what is blocked

19 open items. A page that tells you a feature is not available yet links here, so this list is the answer to where that work has got to.

Blocked by something outside this repository

Work that cannot proceed from here, whatever effort is applied. Each one names what would unblock it.

ItemStateWhat is in the wayWhat would move itPages
EV-1 Evidence verification has never runBlockedThe build environment has no access to PubMed, Cochrane, NICE, any journal or any textbook. Agent 2 of the three agent pipeline is the fact checker and it cannot retrieve a single source.Source access, or a human verifier. Until then no page on this site carries a reference, every verified handoff is marked NOT_RUN_TOOLS_UNAVAILABLE, and no citation has been invented to fill the gap.All 55 published article pages
EV-2 Consultant review has no return pathBlockedReview packs are written to docs/review/ and there is no mechanism for a consultant to return a decision into the pipeline. The deployed design uses a Step Functions task token, and the pipeline is not deployed.Either the pipeline deployed to an AWS account, or an agreed manual route for returning review decisions.55 pages awaiting review
EV-3 The sgit.ai deployment workflow was never readBlockedhttps://sgit.ai/llms.txt returns 403 at the network egress gateway. The host is not on the allow list for this environment.Either the document contents pasted into the chat, or the host allowed through the environment's network policy.
EV-4 The pipeline has never been deployedBlockedNo AWS account, region or budget has been named. The SAM template, the state machine and the Lambda handlers exist and their tests pass locally.An AWS account to deploy into and a monthly budget ceiling for Bedrock.
EV-5 Architecture parts 2 to 6 have not been suppliedBlockedOnly Part 1, covering sections 0 to 3, has been received. Sections 4 to 15 are summarised in Part 1 but have no page level map, so no brief can be generated for them.Parts 2 to 6 of the Master Publishing Architecture from the chat that produced Part 1.
